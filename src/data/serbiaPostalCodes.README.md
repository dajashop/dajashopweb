# Serbia postal codes

The dataset is supplied by GeoNames without a completeness or accuracy guarantee.
Exact normalized matches only; Cyrillic transliteration and Latin diacritic folding
are applied identically to the data and input. Ambiguous place names do not autofill.
Existing manually entered or browser-filled postal codes remain editable and are
not replaced. To refresh, download RS.zip and regenerate the [place, postalCode]
array from columns 3 and 2 of RS.txt; preserve duplicate place names to detect ambiguity.
