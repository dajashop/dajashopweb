### Reporting a Vulnerability

If you discover a security vulnerability, please report it privately.

* Send an email to: [dajashopnis@gmail.com](mailto:dajashopnis@gmail.com)
* Do not open a public issue for security vulnerabilities

You can expect a response within 48 hours.

If the vulnerability is confirmed:

* We will work on a fix as soon as possible
* A patch will be released
* You may be credited for the report

If the vulnerability is not accepted, we will provide an explanation.
